# 新手详细指南与常见问题

## 0. 不设置角色也能开始
上传 ZIP，阅读 CHATGPT.md 后选择默认女性林晚或默认男性江远，口令 `1356`。两位都已具备完整高文学能力。自定义完全可选，详细说明见 [书信文学与角色设置](LETTER_WRITING.md)。

## 1. 如何修改或微调角色卡？
随时直接对你的 ChatGPT 说即可，例如：
- 「把我的神奇信箱角色卡里的称呼改成“阿明”，性格多加一点嘴硬心软。」
- 「把触发口令改成 `2791`。」

## 2. 如何在本地添加自己的私人故事书？
在 `assets/books/` 下新建 `custom_books.json`（已默认加入 `.gitignore`，不会误传到公开仓库），按以下格式添加书目，引擎会自动识别并纳入随机抽架：
```json
{
  "books": [
    {
      "id": "C01",
      "shelf_id": "SC01",
      "title": "你的专属世界书名",
      "chapters": [
        {"id": 1, "title": "章节名", "point": "故事触发瞬间描述", "gender": "全部"}
      ]
    }
  ]
}
```

## 3. 升级与回退说明
- 每次升级建议保留上一版本的发行 ZIP 压缩包。如新版成片观感不如预期，直接在新的 ChatGPT 对话中重新上传旧版 ZIP 即可秒级回退，无需卸载或清理环境。

## 4. 常见错误提示
- `PHOTO_LAYOUT_ASPECT_MISMATCH`：第 6 步版式画幅与第 5 步摄影画幅不一致，按提示选择匹配版式重新编译即可。
- `ASSET_LOCK_MISMATCH`：修改 `role_card.json` 后未同步更新 `asset_lock.json` 中对应哈希，让 ChatGPT 刷新 `role_card` 哈希即可。

## 5. 跨窗口冷却（CD）说明
- 普通 ChatGPT 聊天窗口暂不支持可靠的跨窗口持久化写入，因此当前默认允许偶发重复抽取、不伪造历史记录；架内防偏心递增冷却（`2 → 4 → 6 → 8` + 最近 3 架防连抽）已作为后续持久化环境的候选方案预留。
